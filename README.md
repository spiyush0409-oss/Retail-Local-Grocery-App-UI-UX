# Retail Local Grocery App

## Project Overview
Retail Local Grocery App is a mobile UI/UX design project created in Figma for the Unified Mentor Internship Program.

## Features
- User Authentication
- Product Browsing
- Product Search
- Product Filters
- Product Details
- Cart Management
- Checkout Process
- Order Confirmation
- User Profile

## Tools Used
- Figma
- GitHub

## Screens Included
1. Splash Screen
2. Login Screen
3. Home Screen
4. Product Listing
5. Filter Screen
6. Product Details
7. Cart Screen
8. Checkout Screen
9. Order Success Screen
10. Profile Screen
